view() animations

 

Different from scroll() animations

View animations are based upon the elements visibility inside the nearest ancestor.

Animation timelines

Elements have anonymous view progress timeline to animate.

Horizontal or vertical

Timelines can be defined upon the horizontal or vertical axis


.card {
	animation-timeline: view();
	animation-name: scale;
}
						

@keyframes scale {
	0% {
		transform: scale(0);
		opacity: 0;
	}
	70% {
		transform: scale(1);
		opacity: 1;
	}
	100% {
			transform: scale(0.8);
			opacity: 0;
		}
}

Items can have their own keyframes

Scroll snapping

 

View animations can be functional too

They're not just for eye-candy

Introducing scroll-snap

Allows us to control the anchoring of elements.

It's wonderfully simple to implement too, which is always nice.

scroll-snap-type: x mandatory;
						
@keyframes snap {
	0% {
		opacity: 0;
		transform:  scale(0);
	}
	50% {
		opacity: 1;
		transform: scale(1);
	}
	100% {
			opacity: 0;
			transform: scale(0);
	}
}

You could animate anything

It could be text, images, videos... anything really
